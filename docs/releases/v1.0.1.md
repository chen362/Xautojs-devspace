# Xautojs DevSpace v1.0.1

**Release focus:** native agent workflows, GitHub automation, operator controls, and desktop integration.

Xautojs DevSpace `v1.0.1` consolidates the current local-first AI coding stack around a native agent runtime, auditable execution, GitHub-driven automation, and operator tooling.

## Highlights

### Native agent runtime

- Added and expanded first-party native agent execution and lifecycle handling.
- Added durable run state and event tracking for native-agent workflows.
- Added workflow packs for common development tasks, including:
  - `github-pr-review`
  - `feature-dev`
  - `security-review`
  - `test-fix`
- Added runtime policy, approval, retry, replay, resume, and cancellation flows.
- Added typed runtime hooks and operator-visible hook decisions.

### GitHub and automation

- Added GitHub webhook ingress with signature verification and routing policy.
- Added owner-scoped automation sources and delivery handling.
- Added automation-to-agent dispatch paths for repository-driven workflows.
- Added audit-oriented state for automation and native-agent execution.

### Operator experience

- Added operator APIs for listing runs, replaying execution history, resolving approvals, and controlling execution.
- Added browser operator console for run status, replay timelines, approvals, hook decisions, workflow state, retry, resume, and cancellation.
- Added operator CLI commands for workflow inspection, dispatch, replay, approvals, retry, resume, and cancellation.

### Xautojs Desktop

- Expanded the Tauri desktop operator surface and local daemon integration.
- Added live lifecycle wiring, approval prompt handling, and token/keychain integration.
- Added desktop-side tests covering cloud connection, lifecycle, token, and operator client behavior.
- Kept desktop packaging targets for macOS, Windows, and Linux while signed production installers and updater channels remain future work.

### Reliability and security

- Expanded automated coverage across identity, MCP sessions, workspace stores, automation, GitHub webhooks, native-agent policy, runtime hooks, operator APIs, desktop clients, and cloud routing components.
- Added readiness, migration, configuration, and production smoke checks around the runtime and database layers.
- Kept workspace access explicitly scoped and documented the security model for connected MCP clients.

## Compatibility

- Node.js `>=22.19 <27` is required.
- Node 22 LTS is recommended.
- Linux and macOS are fully supported.
- Windows is supported with Git Bash, WSL, MSYS2, or Cygwin Bash; pure PowerShell/cmd-only shell workflows have limited compatibility.

## Installation from source

```bash
git clone https://github.com/chen362/Xautojs-devspace.git
cd Xautojs-devspace
npm install --include=dev
npm run build
node dist/cli.js init
node dist/cli.js serve
```

## Package

The release package identity is:

```text
xautojs-devspace
```

The installed CLI remains:

```text
devspace
```
